Автотесты для API сервиса [Stellar Burgers](https://stellarburgers.education-services.ru/)



## Примечание

Тест «заказ без авторизации» проверяет ответ `401` строго по документации API.
Реальный сервис на `POST /api/orders` без авторизации отвечает `200`, поэтому этот тест падает: он фиксирует дефект API.
